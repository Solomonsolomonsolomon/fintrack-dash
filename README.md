# FinTrack Dash

FinTrack Dash is a Next.js dashboard project with the following improvements and features:

- Search functionality with debouncing for optimized performance.
- Double header layout implemented for better navigation structure.
- Fixed sidebar that stays visible during scrolling.
- Followed clean coding practices throughout the codebase.
- Fully mobile-first and responsive design for all screen sizes.
- Successfully deployed on Vercel for seamless production hosting.
